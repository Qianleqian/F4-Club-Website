# Week 8 和 Week 9 网站改进日志

日期：2026-11-20。此记录基于本地 `main` 的改动及独立测试数据。它记录实际代码检查和验证，并非真实用户访谈、NVDA/Narrator 测试或课堂小组反馈。

## 公共页面和无障碍

- 修改：增加跳转到主要内容的键盘链接，导航切换后将焦点移到页面标题；为登录和详情弹窗提供可识别标题；图标对屏幕阅读器隐藏。
- 修改：加深辅助文字和焦点轮廓，增大部分辅助文字字号；调整小屏幕搜索区域和顶部布局。状态继续通过文字而不只通过颜色表达。
- 发现并修复：axe-core 首轮扫描在有多张活动卡片时报告一处卡片横幅文字对比度问题；调整文字颜色后复扫未再报告此项。
- 验证：使用 Chrome、axe-core 4.10.3，选用 WCAG 2.0 A/AA 和 2.1 A/AA 标签，扫描公开活动页、登录弹窗、账号管理、社团创建表单、有待审活动的教师审核页、学生报名页；上述页面当次扫描均无对应标签下的自动化违规项。自动扫描不能证明完全符合 WCAG。
- 验证：键盘自动化走过跳转主内容、登录、导航到报名页、打开详情以及 Escape 关闭弹窗；320px 视口下检查页面整体宽度无横向溢出。这不等同于人工屏幕阅读器和真实 400% 浏览器缩放测试。

## 学生 Student

- 修改：活动日期和兴趣筛选后，显示匹配数量；没有匹配结果时提示调整筛选条件。搜索及报名沿用原有的业务规则和错误提示。
- 验证：浏览器检查筛选为无结果、恢复筛选、报名成功、查看报名、二维码和海报；提醒设置、刷新保留及关闭通过浏览器回归。原有 17 项 Kotlin/Ktor 测试通过。

## 社团 Club

- 修改：编辑活动时明确告知需要重新审核并保留报名；新增“放弃修改”返回按钮。编辑公告也可放弃修改，并显示重新审核说明。
- 验证：浏览器检查编辑活动后不保存返回、提交活动、驳回后查看意见并修改重提；公告驳回、修改重审和公开流程通过回归。

## 教师 Teacher

- 修改：活动、公告和社团申请在选择驳回但未填写意见时，页面给出明确提示并把焦点移至意见框；后端原有校验继续生效。
- 验证：在有真实测试用待审核活动的教师页面运行 axe 扫描；模拟空意见驳回，确认焦点和提示；活动和公告的通过、驳回及历史记录通过浏览器回归。

## 管理员 Admin

- 修改：启用或禁用账号前显示包含账号名的确认提示；账号表格操作按钮提供包含账号名的可访问名称。搜索和角色分类增加匹配数量及无结果提示，表格区域支持键盘聚焦。
- 验证：浏览器拒绝确认后检查 student 账号仍处于启用状态；搜索、角色分类、名单查看及账号页 axe 扫描通过。服务器端权限继续由现有测试验证。
